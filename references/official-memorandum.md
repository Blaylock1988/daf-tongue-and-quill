# Official Memorandum, Indorsements, MFR, Minutes & Publications (Ch. 13, 14, 23)

## 1. Official Memorandum Physical Layout (Ch. 14, pp. 163–190)

| Element | Rule & Placement |
| :--- | :--- |
| **Margins** | `20+ lines`: **1"** left/right/bottom; `10–19 lines`: **1"–1.5"**; `1–9 lines`: **1.5"–2"**; continuation pages: **1"** all around. |
| **Font** | **12-pt Times New Roman** (floor 10 pt only to keep signature block off orphan page). Computer-generated **letterhead** centered `5/8"` from top: Line 1 **`DEPARTMENT OF THE AIR FORCE`** (12 pt *Copperplate Gothic Bold*), Line 2 centered `3 pts` below (10.5 pt *Copperplate Gothic Bold*). `[MODERN DAF UPDATE]` USSF orgs retain Line 1 `DEPARTMENT OF THE AIR FORCE` + Line 2 USSF sub-org (e.g., `HEADQUARTERS SPACE BASE DELTA 3 (USSF)`). |
| **Seal** | Optional raster seal placed **`0.5"` from top & left**. `[MODERN DAF UPDATE]` Choose **DoW seal** (EO 14347), **DoD seal**, or **DAF/USSF seal** matching user selection via `--seal auto|<path>`. |
| **Date** | Flush right, **`1.75"` from top edge**, `1"` from right edge. Military format: **`21 November 2026`** or **`21 Nov 26`** (never mix abbreviated month with 4-digit year like `21 Nov 2026`). Civilian: `November 21, 2026`. |
| **`MEMORANDUM FOR`** | **NO colon**; 2nd line below date (1 blank line), **2 spaces** before ALL CAPS `ORG/SYMBOL`. Specific person: `79 FS/DO (LT COL JORGE TORRES)` or `ATTENTION:` / `THROUGH:` aligned under address on line below. Multiple recipients aligned vertically; `IN TURN` typed 1 line below last address. Broad send: `MEMORANDUM FOR  DISTRIBUTION`. `HQ` rule (p. 165): use `HQ` for MAJCOM/HAF staff offices; omit `HQ`/`Headquarters` when addressing MAJCOM Commanders/Vice Commanders directly. |
| **`FROM:`** | **With colon**; 2nd line below last `MEMORANDUM FOR`/`THROUGH:` line, **2 spaces**. Single line (`ORG/SYMBOL`) on same base or printed letterhead; 3-line address if off-installation (`ORG/SYMBOL`, street mixed case, `City ST  ZIP+4` with **no comma** and **2 spaces** before ZIP). |
| **`SUBJECT:`** | **With colon**; 2nd line below `FROM:`, **2 spaces**, Title Case (wrapped lines align under first word). Include rank + full name when subject concerns 1 person (not addressee); omit names for 2+. Add suspense: `(SUSPENSE: 21 November 2026)`. |
| **`References:`** | Optional: 1 ref goes in parentheses after subject; 2+ go on 2nd line below `SUBJECT:` as `References:  (a) ...`, `(b) ...`. Append `(NOTAL)` when not distributed to all addressees. |
| **Body & Outline** | Begins 2nd line below `SUBJECT:`/`References:`. Single-space within, double-space between paragraphs/subparagraphs (single-paragraph <8 lines may double-space). **1 paragraph = unnumbered**. **2+ paragraphs** follow Classic Outline (p. 56, 180): **`1.` -> `a.` -> `(1)` -> `(a)` -> underlined `1.` -> underlined `a.` -> `[1]`** (2 spaces after marker; child marker aligns under first char of parent text; wrapped lines return **flush left**; Cardinal Rule requires >=2 divisions). Put POC (name, DSN, Comm, email) in final paragraph. |
| **Continuation Pages** | Plain bond; page number **`0.5"` from top flush right** starting Page 2 (**Page 1 never numbered**); body resumes **4 lines below** page number; >=2 lines per page; never split <4-line paragraphs. |
| **Authority Line** | **`FOR THE COMMANDER`** (ALL CAPS), 2nd line below text, **`4.5"` from left edge** (3 spaces right of center). Use when designated rep signs, coordinated staff position, or staff directs action in AOR. **Never** use when CC signs personally, when Deputy/Vice signs in temp absence (unless directed by law), for unit opinions, or outside DoD/DoW. |
| **Signature Block** | **5th line below** last text line or authority line (4 blank lines), **`4.5"` from left edge**; **NEVER alone on a continuation page** (set `keep_together`). Dual signatures: junior flush left, senior at `4.5"`. Line 1: `FIRST M. LAST, Rank, Service` (**Name + Service ALL CAPS**; Rank & Duty Title Mixed/Title Case; Col & GO ranks normally spelled out; civilians `GS-15, DAF`; USSF uses `USSF`). Line 2: Duty title (`Acting` allowed for staff titles, **NEVER** for Commander capacity; never sign *"for"* or *"in the absence of"*). **Target 3 lines; hard max 4 lines** (4th line overflow indents under 3rd character of line above). `//SIGNED//` valid for electronic/reproduced copies when wet/CAC original is on file. |
| **Closing Blocks** | `Attachment:` (1) or `# Attachments:` (2+, numbered in citation order) flush left on **3rd line below** signature block (never `as stated`, `a/s`; never split list across pages—use `# Attachments (listed on next page)`). `cc:` flush left on **2nd line below** attachments (or 3rd below sig block); supports `wo/Atch`, `Atch 2 only`. `DISTRIBUTION:` 2nd line below `cc:`/`Attachments`. Page markings (p. 174): lower-right `Atch 1`, multi-page `Atch 1 (1 of 3)`; hierarchy: `Atch` -> `Appendix` -> `Annex` -> `Exhibit`. |

## 2. Memorandum Variants (Indorsements, MFR, AAR, Minutes, Short Note)

- **Indorsements (pp. 182–183):** Used only on official memorandums (never Personal Letters). Ordinals: **`1st Ind`**, **`2d Ind`**, **`3d Ind`**, **`4th Ind`**. Same-page: 2nd line below last element -> `1st Ind, ORG/SYMBOL` flush left + date flush right -> `MEMORANDUM FOR` -> text -> signature block. Separate-page: top line cites `2d Ind to <Orig Org>, <Orig Date>, <Orig Subject>`, 2nd line below shows `<Indorsing Org>` flush left + date flush right.
- **Memorandum for Record (MFR, pp. 188–189):** Three forms:
  1. *Separate-page MFR:* `MEMORANDUM FOR  RECORD`, **omits `FROM:`**, uses modified signature block (`NAME` + `ORG/SYMBOL`).
  2. *Explanatory Note:* Typed on file copy 2nd line below signature block (`MEMO FOR RECORD` + date, signed last name).
  3. *Compact Note:* Hand/typed `MR:` + last name + date.
- **Short-Note Reply (p. 184):** Brief reply written directly on the incoming correspondence copy (`[Date] / Memo to [Org] / [Text] / //SIGNED//`).
- **Meeting Minutes (Ch. 13, p. 158):** Official Memo format, word **`Minutes`** in `SUBJECT:`, past-tense verbs throughout, Paragraph 1 records body name / regular or special / date / time / location, final paragraph records adjournment time & next meeting; recorder signs by board role, followed 2 lines below by **`Approved as written`** and approving official's signature block (`build_doc.py schema minutes`).

## 3. High-Frequency Memo Presets (`build_doc.py schema memo --preset ...`)

1. `appointment`: Unit Additional Duty / GPC / UDM appointment (authority, primary/alternate names, duties, effective & supersession dates).
2. `policy`: Commander Operating / Policy Memo (BLUF rule, applicability, supersession clause, annual review cycle/OPR).
3. `etp`: Waiver / Exception to Policy (cites DAFI 33-360 tiering authority, justification, risk mitigation, sunset date, bottom indorsement).
4. `assumption-of-command`: Cites **DAFI 51-509** `[MODERN DAF UPDATE]` (superseding AFI 51-604), effective date/time, special order, unit assumed, signed as `Commander`.
5. `aar`: Trip / After-Action Report (AFH 33-337 p. 187: traveler, dates/location, purpose, outcomes, follow-up actions, POC).

## 4. Air Force Publications & Forms Overview (Ch. 23, pp. 283–284)

`[MODERN DAF UPDATE]` Governed by **DAFI 33-360** (*Publications and Forms Management*). Recommended changes submit via **AF/DAF Form 847**. Six development stages: 1) *Draft and Collaborate* -> 2) *Staffing* -> 3) *Formal Coordination* -> 4) *Certification* -> 5) *Approval* -> 6) *Publishing*. Avoid repeating the same word as both noun and verb in one sentence (Plain Language Challenge, p. 284).
